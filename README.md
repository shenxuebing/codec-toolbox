# 增强版多功能编解码工具箱

浏览器离线编解码/密码学辅助工具箱，左侧菜单栏 + 右侧内容区布局，共 34 个功能页面。双击 `index.html` 即可使用，除 GitHub 热榜外全部功能无需联网。

（功能分类：编码转换类 → 哈希/密码类 → 文本/开发类 → 生活/资讯类，共 25 页）

## 🚀 使用方法

双击打开 `index.html`（推荐 Chrome/Edge），通过左侧菜单切换功能页面。所有计算均在本地浏览器完成，数据不离开本机。

## 📋 功能特性

### 🔄 Base64 / Hex 转换
- Hex ↔ Base64 互转，自动识别输入格式
- 兼容 Base64URL 变体（`-`/`_` 字符、省略 `=` 填充，JWT 等场景）

### 🔤 字符串编码转换
- 字符串 ↔ Hex / Base64 双向转换，支持 UTF-8 和 GBK 编码
- 二进制数据保护：检测到 U+FFFD 替换符（数据不是合法文本）时显示黄色警告；"保存原始字节(.bin)"按钮可无损保存解码字节
- 大数组分块处理，超长输入不爆栈

### 🔗 URL 工具
- URL 编码/解码：encodeURIComponent（参数模式）与 encodeURI（整URL模式）
- URL 参数解析：自动拆解 query 参数表格（参数名/解码值/原始值）

### 🇺🇳 Unicode 转换
- 字符串 ↔ `\uXXXX` 转义序列互转（emoji 等增补平面字符正确往返）

### 🎲 随机字节生成
- Web Crypto 密码学安全随机字节（1 ~ 1048576 字节，超 65536 自动分批）
- 同时输出大写 Hex 与 Base64，适合生成密钥/盐/IV

### 🔒 哈希计算
- MD5、SHA-1、SHA-256、SHA-512、SM3（国密），每种算法同时输出 Hex 和 Base64
- 输入格式支持文本（UTF-8/GBK）/Hex/Base64

### 🧬 ASN.1 查看器
- 粘贴 PEM/纯 Base64/Hex 或上传 .cer/.der 文件，解析为缩进树形结构
- 每节点显示 Tag 名、偏移、头长度/内容长度、智能预览（OID→点分+名称、UTCTime→格式化时间、INTEGER→十进制+Hex、BIT STRING 未用位数等）
- 内置国密 OID 映射（SM2 曲线/SM3/SM4/SM2-with-SM3，1.2.156.10197 分支自动标注"国密"）与常用 X.509/PKCS OID 名称
- OCTET STRING 内容恰好为合法内嵌 DER 时自动递归展开（PKCS#8/信封常见）；点击节点复制完整 Hex
- 错误定位到"第 N 字节附近"，多字节 Tag 与 DER 不定长（0x80）拒绝等边界均有处理

### 🪪 X.509 证书查看器
- 粘贴 PEM/Base64/Hex 或上传证书文件，结构化展示版本/序列号/签名算法/Issuer/Subject DN/有效期/公钥/扩展项/签名值
- 有效期状态实时判断（未生效/有效期内含剩余天数/已过期），红绿标注
- 公钥智能解析：RSA 模长位数、EC/SM2 曲线名与未压缩点
- 扩展项结构化：keyUsage 启用位、basicConstraints CA 与 pathLen、subjectAltName 各类名称
- 国密证书支持（SM2 曲线/SM2-with-SM3 签名 OID 命中）；可一键跳转 ASN.1 查看器看原始树

### 🧭 OID 查询（PKI / 密码）
- 内置 130 条精选 OID，其中国密 71 条按 **GM/T 0006-2023《密码应用标识规范》** 及 **GM/T 0009（SM2 使用规范）/ GM/T 0010（加密签名消息语法，含 sm2SignedData 等六类内容类型）/ GM/T 0092（证书申请语法）/ GM/T 0093（证书与密钥交换格式）** 全量补齐：SM2/SM3/SM4/SM9/ZUC/SM1/SM7 全家族（含 SM4 全部 13 种工作模式、SM2 无证书/隐式证书/协同签名、SM9 IBC 全套、组合运算机制、密码服务机构与标准体系），出处标注 GM/T 0006/0009/0010/0092/0093 及 GB/T 32918·32907·32905 等对应国标；另有 RSA/PKCS、ECC/NIST、X.509 与 DN、EKU 与 AIA 四大分类，每条含中英文名/分类/出处标准/说明
- 查询：点分 OID 精确命中、Hex（自动剥离 06 TLV 头）解码查询、名称关键字模糊搜索
- 未收录 OID 显示分支归属提示（国密分支/RSA/PKCS/SEC ECC/X.500/IANA）
- Hex ↔ OID 双向互转（base-128 编解码，支持 ≥128 的大弧度值，双向一致性验证）
- 库浏览表分类过滤 + 实时搜索

### 🔢 进制转换
- 2/8/10/16/36/62 进制互转，任意长度大整数（BigInt）
- 支持 0b/0x/0o 前缀、负号、千分位逗号输入；非法字符报出位置
- 62 进制数字表 0-9 a-z A-Z

### 🆔 ID 生成器（UUID / NanoID / ULID）
- UUID v4（随机）与 v7（时间戳有序，RFC 9562）两种版本，基于 Web Crypto
- NanoID（默认 21 位，64 字符表）与 ULID（26 位 Crockford Base32，时间戳单调递增）
- 批量生成 1-1000 个，大小写与去连字符选项

### 🔑 密码生成器
- 长度滑块 4-128，四类字符集勾选（大写/小写/数字/符号）
- 排除易混淆字符（0O1lI）、保证每类至少 1 个、批量 1-100 个
- 强度按信息熵估算五档显示（非常弱~非常强），每个密码独立复制按钮

### 🔁 正则测试器
- 实时匹配（防抖 400ms），匹配片段黄色高亮，统计匹配数/分组数/耗时
- 分组捕获表格（含命名组）、替换预览（$1 引用）、常用正则速查一键填入
- 零宽匹配防死循环保护，非法正则显示引擎原始错误

### 📊 文本 Diff 对比
- 经典 LCS 逐行差异（2000 行内），统一视图左右行号 + =/−/+ 标记
- 新增绿底/删除红底高亮，统计新增/删除/相同行数
- 可选忽略行首尾空白、忽略大小写，一键交换左右文本

### 🌐 IP 子网计算器（IPv4）
- 支持 CIDR（a.b.c.d/nn）与 IP+点分掩码两种输入，掩码连续性校验
- 输出网络地址/广播地址/掩码/反掩码/可用主机范围与数量/IP 类型（私有/公网/环回等）二进制表示
- /31 与 /32 按 RFC 3021 特殊口径处理；段越界、前缀超范围等错误定位到段

### 🔏 HMAC 计算
- 一次性计算 HMAC-SHA1/SHA-256/SHA-384/SHA-512，基于 Web Crypto
- 密钥支持文本/Hex/Base64 三种输入格式，输出 Hex/Base64

### 🔐 AES 加解密
- ECB/CBC 模式 × PKCS7/无填充，密钥 128/192/256 位（Hex 或文本输入，随机生成）
- 输入文本/Hex/Base64，输出 Base64/Hex；与 Node crypto 逐字节对拍一致
- PBKDF2-SHA256 口令派生密钥（自定义盐与迭代次数，Web Crypto）

### 🛡️ 国密 SM2/SM4
- SM4 加解密：ECB/CBC × PKCS7/无填充，输入支持文本(UTF-8)/Hex/Base64，输出 Hex/Base64，随机密钥/IV 生成
- SM3 摘要：支持文本/Hex 输入
- SM2 密钥对生成、PKCS#8 PEM/Base64 私钥提取（自动定位 32 字节私钥段）、**私钥转 PKCS#8 PEM 生成**（与 GmSSL/OpenSSL 兼容，结构经 1.key 实样字节级对拍）
- SM2 加解密（C1C3C2 新国标 / C1C2C3 旧标准）与签名验签（SM3 预处理、DER 编码、UserId 可配）
- **SM2 密文格式互转**：裸 C1C3C2/C1C2C3 ↔ DER/ASN.1（GM/T 0010 SM2Cipher），打通 sm-crypto 与 GmSSL 密文互通；DER INTEGER 符号零与坐标定长还原均正确处理
- **EnDataUtil 格式兼容**：与 EnDataUtil.dll 的 SM4EnData/SM4DeData 封装格式完全互通（固定 yKey + 随机数经 SM3对折→取反→MD5→对折→SM3→MD5 派生密钥），解密支持 random 大小写自适应，已用样例逐字节对拍验证

### 🏷️ HTML 实体编解码
- 基础五保留字（& < > " '）与全量非 ASCII（&#xNNNN;）两种编码范围
- 解码用浏览器原生 textarea 实体机制，支持全部命名/数字实体；附常用实体速查表

### 🧹 文本批量处理
- 去行首尾空白、删空行、行去重（保持首次出现）、排序（可降序）、转小写/转大写（互斥）
- 处理前后字符/行数对比统计，UTF-8 字节数统计，结果可下载

### 🗜️ 图片压缩/缩放
- canvas 本地压缩，目标格式 JPEG/WebP/PNG，质量滑块（10-100）与最长边缩放
- 压缩率带颜色提示（变小绿/变大红），一键下载

### 🗄️ SQL 格式化
- 基于 sql-formatter（本地化内置），支持标准 SQL/MySQL/PostgreSQL/SQLite/PL-SQL/T-SQL 方言
- 缩进 2/4/Tab，关键字大写或保持原样；压缩为一行功能

### 📁 文件工具
- 拖拽或点击选择文件，计算五种哈希（与文本页签结果一致）
- 文件 → Base64 / Hex，超 10 万字符界面截断 + 一键下载完整结果

### 🕐 时间戳转换
- 实时显示当前秒级/毫秒级时间戳
- 时间戳 → 日期（10/13 位自动识别）：本地时间、UTC、ISO 8601、相对描述
- 日期 → 时间戳（datetime-local 选择，秒级/毫秒级输出）

### 🔑 JWT 工具
- 解码：任意算法 JWT 展示 header/payload/签名（Base64URL + Hex），exp/iat/nbf 时间字段人性化显示并标注是否过期
- 签发：HS256（HMAC-SHA256，Web Crypto），payload 模板 + 密钥
- 验证：HS256 签名比对 + 过期检查；签发→验证闭环测试与 jwt.io 官方示例对拍一致

### 📋 ASCII 码对照表
- 0-127 标准区 / 128-255 扩展区（Latin-1 + CP1252 重排说明）
- 十进制/十六进制/八进制/字符/中文名称五列，支持搜索过滤，点击行复制

### 🗂️ JSON 工具
- 格式化（缩进 2/4/8 可选）与压缩
- 校验：错误信息附带行列定位
- 中文转 `\uXXXX` 转义显示开关
- 转义为字符串字面量 / 去转义（代码嵌入场景）

### 🖼️ 图片 Base64
- 图片 → Base64：拖拽/点击选择，实时预览与宽高信息，输出完整 Data URI 或纯 Base64，附 CSS/HTML 用法示例
- Base64 → 图片：粘贴 Base64/Data URI 或直接 Ctrl+V 粘贴图片，即时预览并可下载还原图片文件

### 📡 二维码工具
- 生成：文本 → 二维码（尺寸 128/256/384、纠错级别 L/M/Q/H），支持下载 PNG 与 SVG
- 识别：拖拽/粘贴二维码图片 → 还原文本（URL 自动生成可点击链接），过小图片自动放大提高识别率

### 🎂 年龄计算
- 周岁（日历逐月借位精确到 X 岁 Y 个月 Z 天）、总天数/小时/分钟
- 下次生日倒计时与星期、生肖、星座、出生当天星期（闰年 2/29 生日按 3/1 修正并注明）
- 农历信息：出生日期的农历表示（含闰月注明）、下次农历生日的公历日期与倒计时（支持 1900-2049，出生在闰月/三十等边界场景自动降级并注明）

### 🔥 GitHub 热榜（唯一联网功能）
- 按创建时间 + 星数近似热榜（最近 1/7/30 天）或总榜，语言筛选，Top 25
- 请求固定发往 api.github.com（HTTPS），未认证限额每小时 60 次；离线时友好提示，不影响其他功能
