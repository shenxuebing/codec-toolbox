# 紧凑版多功能编解码工具

这是一个完全离线的HTML编解码工具，支持多种编码转换和哈希计算功能，采用紧凑布局设计，确保所有内容在一页内显示。

## 📋 功能特性

### 🔄 编码转换
- **Hex ↔ Base64**: 支持十六进制与Base64之间的相互转换
- **字符串编码转换**: 
  - 字符串 ↔ Hex
  - 字符串 ↔ Base64
  - Hex ↔ 字符串
  - Base64 ↔ 字符串
- **编码支持**: UTF-8 和 GBK 编码
- **文件保存**: 支持将字符串转换结果保存到本地文件
- **复制功能**: 所有结果区域都有复制按钮，哈希结果区域有独立的复制按钮
- **文件名输入**: 保存文件时可以使用浏览器自带的文件名输入对话框

### 🔗 URL / Unicode / 随机字节
- **URL 编解码**: 支持 encodeURIComponent（参数模式）与 encodeURI（整URL模式）两种模式互转，解码失败时给出明确提示
- **Unicode 转义**: 字符串 ↔ `\uXXXX` 转义序列互转（4 位十六进制小写），无转义序列时明确提示
- **随机字节生成**: 基于 Web Crypto API 生成密码学安全的随机字节（1 ~ 1048576 字节，超 65536 字节自动分批生成），同时输出大写 Hex 与 Base64，适合生成密钥/盐/IV

### 🔒 哈希计算
- **MD5**: 支持Hex和Base64输出格式
- **SHA-1**: 支持Hex和Base64输出格式
- **SHA-256**: 支持Hex和Base64输出格式
- **SHA-512**: 支持Hex和Base64输出格式
- **SM3**: 国密算法哈希，支持Hex和Base64输出格式

### 📁 文件工具
- **文件哈希**: 对本地文件计算 MD5/SHA-1/SHA-256/SHA-512/SM3，支持Hex和Base64输出格式，结果与文本页签对相同内容计算一致
- **文件转Base64/Hex**: 将本地文件内容编码为 Base64 或 Hex（大写），适用于 Data URI、文件校验等场景
- **拖拽选择文件**: 支持拖拽或点击两种方式选择文件，自动显示文件名、大小（B/KB/MB/GB）和类型，大文件（>50MB）自动提示
- **大结果下载**: 转换结果超过 10 万字符时界面截断显示，可一键下载完整结果为 `.base64.txt` / `.hex.txt`

### 🎨 用户界面
- **紧凑布局**: 所有内容在一页内显示，无滚动条
- **响应式设计**: 支持桌面和移动设备
- 直观的标签页界面
- 实时结果显示
- 一键复制功能和文件保存功能

## 🚀 使用方法

### 直接打开
1. 双击 `增强版编解码工具.html` 文件
2. 浏览器会自动打开工具
3. 无需联网，完全本地运行

### 编码转换使用
1. 选择相应的标签页（Hex/Base64 或 字符串转换）
2. 在输入框中输入要转换的内容
3. 选择编码类型（UTF-8 或 GBK）
4. 点击相应的转换按钮
5. 结果会显示在下方结果区域
6. **新增功能**：点击"保存结果到文件"按钮可以将转换结果保存为本地txt文件

### 哈希计算使用
1. 在哈希计算区域输入要计算的内容
2. 选择编码类型（UTF-8 或 GBK）
3. **选择输出格式（重要更新）**: 
   - 可以选择输出格式：Hex（默认）或 Base64
   - 所有哈希算法都支持两种输出格式
4. 点击"计算所有哈希"或单个算法按钮
5. 等待计算完成查看结果

### 文件保存功能
- **智能文件名**：根据输入内容自动生成文件名
- **UTF-8编码**：确保文件支持中文字符
- **一键保存**：无需手动复制粘贴
- **浏览器集成**: 使用浏览器原生的文件保存对话框，支持文件名输入

## 💡 特色功能

### 🔄 哈希输出格式选择（新功能）
- **Hex输出**（默认）: 传统的十六进制格式
- **Base64输出**: 新的Base64格式选项
- 所有哈希算法（MD5、SHA-1、SHA-256、SHA-512、SM3）都支持两种输出格式

### 🔍 自动识别转换
在Hex/Base64转换页面，点击"自动识别转换"按钮，工具会自动检测输入内容的格式并进行相应转换。

### ⚡ 快速测试
工具内置了快速测试按钮，可以一键测试常见的功能：
- Hello(Hex): 测试Hex转Base64
- Hello(Base64): 测试Base64转Hex
- 中文测试: 测试中文字符串编码转换
- Hash测试: 测试哈希计算功能

### 📋 复制功能
- 结果区域右上角有复制按钮
- 哈希结果每个都有独立的复制按钮
- 支持一键复制到剪贴板

### 文件保存

- **保存位置**: 文件将保存到浏览器的默认下载文件夹
- **文件内容**: 只保存转换结果，不包含额外的元信息

1. **离线使用**: 工具完全离线运行，无需网络连接
2. **数据安全**: 所有数据都在本地处理，不会上传到服务器
3. **浏览器支持**: 建议使用现代浏览器以获得最佳体验
4. **大文件处理**: 建议处理的内容不要过大，以免影响性能
