🔄 SM2 密文格式互转

GmSSL / 标准工具输出的 SM2 密文为 ASN.1 DER（GM/T 0010 SM2Cipher），sm-crypto 等库输出裸密文（C1C3C2 或 C1C2C3，96+ 字节 hex）。本工具双向互转实现互通。

💡 裸密文不含 04 前缀（C1 为 x||y 两个 32 字节坐标）；DER 结构为 SEQUENCE { INTEGER x, INTEGER y, OCTET STRING hash(32B), OCTET STRING cipherText }，坐标按 DER INTEGER 规则去前导零、最高位为 1 时补 0x00。输出统一为大写 Hex。

🗝️ GM/T 0009 加密密钥对解密

GM/T 0009 密钥对保护格式 = SM2 数字信封：SM4 对称密钥加密 SM2 私钥，SM2 公钥加密对称密钥。头部字段存在 1B/1B/1B（布局 A）与 1B/3B/4B（布局 B）两种实现口径，本工具自适应解析（先按 A，字段越界/不合理再按 B）。

解密后此处显示头部字段 / 对称密钥 / 解出的 SM2 私钥与 PKCS#8 PEM

💡 SM2 密钥密文依次尝试 裸 C1C3C2 / 裸 C1C2C3 / DER（GM/T 0010 SM2Cipher）三种形态；sm-crypto 0.3.2 的 doDecrypt 只返回 UTF-8 文本，本工具生成侧按"密钥 Hex 文本"口径加密——设备若按 16 原始字节加密且非合法 UTF-8 将无法还原。EnDataUtil 口径的密钥文件（如 sm2_app.enc）请到"国密 SM2/SM4"页的"EnDataUtil 格式兼容"区解密。

🗝️ GM/T 0009 加密密钥对生成

生成后此处显示保护数据（大写 Hex / Base64）与自测回解结果

💡 流程：随机 16 字节 SM4 密钥 → SM4-ECB/PKCS7 加密私钥 → SM2（C1C3C2）加密 SM4 密钥 → 按布局 A 组装（01 01 + 1B 密钥密文长度 + 密钥密文 + 2B 大端私钥密文长度 + 私钥密文 + 公钥 64B（剥 04））。生成后立即回解自测（与本页解密函数对拍），私钥逐字节一致。

📇 GM/T 0016/0018 密钥（ENVELOPEDKEYBLOB）

GM/T 0016《智能密码钥匙密码应用接口规范》/ GM/T 0018《密码设备应用接口规范》导出的 ECC 密钥对保护结构（SKF_ExportSignPriKey / SDF_ExportSignKey_ECC 输出）：C 结构体内存映像、ULONG 一律小端；SM4 加密私钥 + SM2 加密对称密钥，与 GM/T 0009 数字信封同构、可互转。

按上方操作单选执行后此处显示字段表与解密 / 转换产物

💡 字节布局（固定头 372 字节 + 变长 Cipher，总长 ≥ 388）：Version(4) + ulSymmAlgID(4) + ulBits(4) + cbEncryptedPriKey(64，SM4 密文右补零) + PubKey{BitLen(4)+X(64)+Y(64)} + ECCCipherBlob{X(64)+Y(64)+HASH(32)+CipherLen(4)+Cipher}。定长 64 字节坐标按 C 惯例右对齐（256 位值放末 32 字节），解析时自适应探测左右对齐；解密按 SM4-ECB 三口径自适应（前 48B PKCS7 / 前 32B 裸解 / 全 64B PKCS7）；对称密钥 SM2 密文按 C1C3C2 解，失败自动改试 C1C2C3；生成与转换均自带回环自校验。

📑 PDF 合并 / 拆分

💡 合并不依赖第 1 节选择的文件；"每页拆分"则基于第 1 节选择的文件，把每一页导出为独立的单页 PDF 并打包。

🧽 去水印（安全途径）

⚠️ 浏览器端无法去除 PDF 内容流中的文字/图片水印，本工具只提供两种安全遮蔽途径：① 裁剪页边——对固定在页边的水印有效；② 盖白矩形——对固定矩形区域的水印有效。局限：盖白矩形只能盖住绘制次序在其之前的内容，若矩形区域上层还有正文，正文会被一并遮挡；裁剪只是视觉裁剪（CropBox），原始内容字节仍保留在文件中。坐标均为 pt（1 pt = 1/72 英寸），原点在页面左下角，不随页面旋转交换。

📉 PDF 压缩（栅格化重编码）

⚠️ 压缩原理：把每一页渲染为位图，再以 JPEG 重新封装成新 PDF，体积通常显著减小；代价：压缩后文本不再可选中、不再可搜索，清晰度随 DPI / 质量设置下降。矢量内容的无损压缩无法在浏览器端完成，本功能是"有损压缩"。基于第 1 节选择的文件操作，加密口令 PDF 不支持。
