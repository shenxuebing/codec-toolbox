🔑 SM2 密钥与加解密

💡 加密使用公钥、解密使用私钥；密文不含 04 前缀；加密 / 解密的"密文排布"选项必须一致。

✍️ SM2 签名 / 验签

💡 签名 / 验签双方须使用一致的 SM3 预处理、DER 编码与 UserId 设置；SM3 预处理(ZA) = 国标 GM/T 0009 规范签名（对 ZA||M 做 SM3），选"否"则直接对消息做 SM3。

🔁 EnDataUtil 格式兼容

💡 此页签与 EnDataUtil.dll（SM4EnData / SM4DeData）完全互通：解密可打开 testEnDataUtil.exe 加密的任意输出（如样例 Aa123456 ↔ B9F2EF55...，以及打包数据中的私钥段）；加密输出可被该 DLL 直接解密。已逐字节对拍验证。

🔄 SM2 密文格式互转

GmSSL / 标准工具输出的 SM2 密文为 ASN.1 DER（GM/T 0010 SM2Cipher），sm-crypto 等库输出裸密文（C1C3C2 或 C1C2C3，96+ 字节 hex）。本工具双向互转实现互通。

💡 裸密文不含 04 前缀（C1 为 x||y 两个 32 字节坐标）；DER 结构为 SEQUENCE { INTEGER x, INTEGER y, OCTET STRING hash(32B), OCTET STRING cipherText }，坐标按 DER INTEGER 规则去前导零、最高位为 1 时补 0x00。输出统一为大写 Hex。

🔑 SM2 私钥转 PKCS#8 PEM

与上方“从 PKCS#8 PEM 私钥提取”互为逆操作；生成的 PEM 可被 GmSSL / OpenSSL 直接使用。

💡 结构为 RFC 5958 PrivateKeyInfo：SEQUENCE { INTEGER 1, OCTET STRING(32) 私钥, [0] SM2 曲线 OID 1.2.156.10197.1.301, [1] 公钥 BIT STRING（可选） }。自测锚点：私钥 cec3bd2d... 生成的 DER 前缀应为 30770201010420。
